# Drinco-FMCG-Modelling-Project
• Analysed 88K+ FMCG transactional records across product, brand, customer, channel, volume, sales, discounts, COGS, distribution, and warehousing to build a management reporting and financial performance model using Advanced Excel, Pivot Tables, and GETPIVOTDATA.
• Developed a sales and profitability analysis dashboard comparing 2015–2016 performance, calculating Net Sales, Gross Profit, Gross Profit %, and Full Delivered Margin, with absolute and percentage variance analysis to identify key financial and operational performance drivers.
