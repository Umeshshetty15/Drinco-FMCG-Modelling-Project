# Drinco-FMCG-Modelling-Project
Built an interactive FMCG P&amp;L dashboard in Excel using 2015–16 monthly transaction data, PivotTables, GETPIVOTDATA and 6 slicers for dynamic SKU/client analysis. Automated YoY variance and Gross Profit % tracking, identifying ~9% GP decline driven by lower volume and margin compression.
